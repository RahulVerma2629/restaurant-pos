# Restaurant Management System

A modular Restaurant Management System / POS designed to manage restaurant operations including orders, kitchen operations, billing, payments, inventory, customers, users, dashboards, reporting and audit.

## Project Structure

The project is organized into independent modules so that multiple team members can work on different functional areas while maintaining one common project architecture.

## Main Modules

- Order & Front-of-House
- Billing & Payments
- Inventory & Customer Operations
- Security, RBAC & Dashboards
- Architecture, Integration & Reliability
